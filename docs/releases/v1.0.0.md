Folio’nun ilk masaüstü yayını. Markdown dosyalarını yerel olarak okuma, görsel düzenleme ve paylaşma araçlarını bir araya getirir.

**Website / Web sitesi:** https://onurcankaraman.github.io/folio-markdown/

### Bu sürümde

- Okuma, görsel düzenleme, kaynak ve bölünmüş görünüm.
- Görsel tablo araçları, CSV/TSV, LaTeX formülleri ve Mermaid diyagramları.
- Word benzeri sayfa yakınlaştırması (%25–%300), trackpad sıkıştırma/açma, iki eksenli kaydırma, genişliğe sığdırma ve klavye kısayolları. Yazı boyutu ayrıca ayarlanabilir.
- Yerel dosya kaydetme, değişiklik çakışmaları, belge geçmişi ve kurtarma.
- PDF, bağımsız HTML ve görsellerle ZIP dışa aktarma.
- Açık/koyu tema; Türkçe ve İngilizce arayüz.
- Windows MCP çalışma alanı yolları için native realpath çözümlemesi.

### Paket seçimi

| Sistem | Mimari | Paket |
| --- | --- | --- |
| macOS | Apple Silicon / Intel | DMG kurulum veya ZIP |
| Windows | x64 / ARM64 | Setup.exe kurulum veya Portable.exe |
| Linux | x64 / ARM64 | AppImage veya DEB |

Dosya adındaki `arm64`, `x64`, `x86_64` veya `amd64` bölümünü cihazınla eşleştir. Kaynak kod arşivleri çalıştırılabilir uygulama değildir.

### Doğrulama ve sınırlamalar

Paketler GitHub Actions üzerindeki altı platform/mimari işinde çekirdek ve kullanıcı akışı testlerinden sonra oluşturulur. `SHA256SUMS` dosya bütünlüğü özetlerini, `sbom.json` bağımlılık envanterini, `THIRD_PARTY_LICENSES.txt` üçüncü taraf lisans bildirimlerini içerir.

**Bu paketler imzasızdır; Apple noter onayı ve Windows yayıncı imzası içermez.** İşletim sistemi yayıncı doğrulama uyarısı gösterebilir. Otomatik kurulum/güncelleme beslemesi bu yayına dahil değildir. Yeni paketi bu sayfadan indirerek güncelleyebilirsin.

Tam üretim kabulü henüz tamamlanmamıştır. Fiziksel trackpad ve her işletim sisteminde son kullanıcı kurulum kabulü ayrı kontrollerdir. Açık maddeler [teslimat kontrolünde](https://github.com/onurcankaraman/folio-markdown/blob/main/docs/TESLIMAT_KONTROLU.md) takip edilir.

### English

First desktop release of Folio: a local-first Markdown reader and visual editor, with tables, LaTeX math, Mermaid diagrams, whole-page zoom and PDF/HTML/ZIP exports. Choose your OS and CPU architecture from the attached assets.

**Binaries are unsigned and macOS builds are not notarized.** Full production acceptance is still in progress. Checksums, dependency inventory and third-party license notices are attached. See the delivery checklist for known limitations.
